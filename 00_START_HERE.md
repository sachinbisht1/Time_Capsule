## 🚀 How to Get Started (3 Minutes)

### Step 1: Backend Setup
```powershell
cd backend
python -m venv venv
.\venv\Scripts\Activate
pip install -r requirements.txt
python run.py
```

### Step 2: Frontend Setup (New Terminal)
```powershell
cd frontend
npm install
npm start
```

### Step 3: Start Using!
- Open **http://localhost:3000**
- Register account
- Create memory in Creator mode
- Find it in Visitor mode
- View when within 2 meters

**Done! App is running! 🎉**

- Shows all capsules within 1km on map
- Auto-discovers when moving
- Updates continuously

**Unlock Range**: 2 meters radius  
- Must be within 2m to view content
- Precise distance verification
- Security through proximity

**Distance Calculation**:  
- Uses Haversine formula
- Accurate to ±50 meters
- Works with GPS coordinates

## 🔑 How to Customize

### Change Discovery Radius
Edit `backend/app/routes/capsule.py` line 95:
```python
radius_km = 1  # Change to 2, 5, etc.
```

### Change Unlock Distance
Edit `backend/app/routes/capsule.py` line 110:
```python
if distance > 2:  # Change to 5, 10, etc.
```

### Add Database Fields
Edit models in `backend/app/models/` and run database reset:
```python
db.drop_all()
db.create_all()
```

### Change UI Colors
Edit `frontend/src/App.css` - update color variables
